# Pyrometer Data Pre-processing: Calibration & Compression (ATP-2 & ATP-3)
**Author:** Avula Ajay Kumar  
**Individual Contribution for:** AP&T Industrial Master Thesis Project

This module contains the software implementation for the Sensor Calibration (ATP-2) and Additional Data Compression (ATP-3) stages of the pyrometer pre-processing pipeline.

## 1. Industrial Context (AP&T Use Case)
In AP&T’s press-hardening lines, pyrometers are used to monitor the temperature of steel blanks heated to ~900°C. However, accuracy is compromised by **emissivity drift**—a physics-based error where the surface properties of the metal change during heating and oxidation. 

The scripts in this folder are designed to:
1. **Calibrate:** Correct emissivity-induced errors in real-time using Machine Learning to match a high-accuracy thermocouple reference (ATP-2).
2. **Compress:** Reduce the massive data volumes generated by industrial sensors using near-lossless and probabilistic methods to support Smart Factory storage (ATP-3).

## 2. Methodology & Scripts

### Sensor Calibration (ATP-2)
Focused on tracking non-linear emissivity changes that classical filters cannot capture.
* `ml_calibrate.py`: Implements Random Forest (top performer), MLP, Gradient Boosting, and SVR architectures.
* `calibrate.py`: Implements the linear regression baseline and drift correction.
* `classical_methods.py`: Implements Mean Offset, Polynomial (deg=2), and Piecewise Linear calibration models.

### High-Fidelity Compression (ATP-3)
Focused on the trade-off between absolute accuracy and storage ratio.
* `compress.py`: Implements **Delta Encoding**, providing a near-lossless reconstruction (RMSE 0.10°C).
* `ml_compress.py`: Implements **Variational Autoencoder (VAE)** and Deep Autoencoder for high-ratio (10.7x) probabilistic compression.

## 3. Data Justification (NIST as a Scientific Proxy)
Fredrik Sikström (Examiner) noted the use of internet-sourced data. This choice is scientifically justified as follows:
* **The Limitation:** The industrial **PODFAM (AP&T)** dataset lacks a physical thermocouple reference channel. Without a "Ground Truth" target, it is mathematically impossible to train or validate supervised Machine Learning models for calibration.
* **The Solution:** The **NIST Additive Manufacturing Dataset** was utilized as a high-fidelity proxy. It provides melt-pool signals with a measurable reference, allowing for the rigorous validation of the ML architectures.
* **Impact:** Once AP&T production lines are instrumented with thermocouple reference trials, the models in this repository can be retrained and deployed directly to the factory floor.

## 4. How to Reproduce Results
1. Ensure the `Layer01.mat` (NIST) or PODFAM `.pcd` files are in the data directory.
2. Run `python layer01_pipeline.py` to execute the end-to-end flow.
3. Run `python d3_comparison.py` to generate the ATP-2 performance metrics.
4. Run `python visualise.py` to view the **AP&T Industrial Monitoring Dashboard** (D4).
